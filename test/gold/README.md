# Gold Markdown files

Fixtures that every release must open, render, round-trip and export without
errors.

| File                 | Flavour                                                              | Purpose                                                                                                               |
| -------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `01-commonmark.md`   | CommonMark 0.31                                                      | every core construct and its edge cases                                                                               |
| `02-gfm.md`          | GitHub Flavored Markdown                                             | tables, task lists, strikethrough, autolinks, footnotes                                                               |
| `03-extended.md` | constructs the editor does not interpret (Markdown Extra / MultiMarkdown / Pandoc); the fixture for "unsupported syntax survives a save" | definition lists, attributes, math, marks, directives, abbreviations |
| `04-stress-book.md`  | book                                                                 | \~2 MB generated by `scripts/gen-stress-book.ts` (seeded, deterministic); performance budget in `PROPOSAL-v2.md` §8.5 |
| `05-network-bait.md` | any                                                                  | remote images, CSS, fonts and links; must load nothing when offline                                                   |
| `06-comic-script.md` | comic                                                                | pages, panels, captions, balloons, SFX                                                                                |

`roundtrip/<name>.md` is what the editor writes back after loading `<name>.md`
(recorded by `test/view/editor.test.ts`; re-record with `UPDATE_GOLD=1` after a
Milkdown upgrade and review the diff). It documents Milkdown's normalisation:
setext headings become ATX, `__strong__` becomes `**strong**`, entities are
decoded, `~~~` and indented code become \`\`\` fences, `*`/`+` bullets become
`-`. Expected HTML exports are added as the exporters land.

The CommonMark examples in `01-commonmark.md` are adapted from the CommonMark
specification (<https://spec.commonmark.org/>, CC-BY-SA 4.0).

Regenerate the stress book with:

```sh
bun scripts/gen-stress-book.ts            # 2 MiB, seed 20261016
bun scripts/gen-stress-book.ts 5242880    # 5 MiB
```
